# بريد العمليات المنفذة عبر Outlook

يعاين المشرف أو محاسب البنوك عمليات تاريخ التنفيذ بتوقيت الرياض. يُدرج التقرير العمليات المنفذة فعليًا والمعتمدة من المشرف والمدير المالي فقط. فتح التاب أو ربط الحساب لا يرسل رسالة؛ الإرسال يتم بالزر الصريح بعد المعاينة ومن حساب الموظف المطابق لبريده في النظام.

## إعداد مسؤول Microsoft 365

1. من Microsoft Entra ID، سجّل تطبيقًا باسم «مركز التحكم المالي» لحسابات المؤسسة فقط، Single tenant.
2. أضف منصة Single-page application، وعنوان العودة:
   `https://sanam-finance-cloud-pilot-mohammedmustafa8016-6001.vercel.app/outlook-callback.html`
3. أضف صلاحيتي Microsoft Graph من نوع Delegated: `User.Read` و`Mail.Send`. امنح الموافقة اللازمة بحسب سياسة المستأجر. لا نحتاج صلاحيات Application أو قراءة الرسائل أو كلمة مرور أو Client secret لهذا المسار.
4. سلّم المدير المالي Application (client) ID وDirectory (tenant) ID؛ المعرفان ليسا أسرارًا.
5. يسجل المدير المالي المعرفين والمستلمين To/Cc في «الإدارة والرقابة ← الأتمتة ← إعداد البريد اليومي»، ثم يفعّل الإرسال. عدم اكتمال الإعداد يبقي المعاينة متاحة والإرسال معطلًا.

## الحماية والتتبع

- Authorization Code مع PKCE وstate عشوائي، وتحقق من مصدر نافذة العودة. رمز Outlook يبقى في الذاكرة فقط، ولا يوضع في قاعدة البيانات أو التخزين المحلي.
- يتحقق الخادم من جلسة النظام، وبريد Microsoft Graph، وصلاحية المرسل، ونسخة البيانات التي تمت معاينتها. لا يقبل جسم رسالة أو مستلمين من المتصفح.
- تحفظ قاعدة البيانات لقطة التقرير وحالة المحاولة، مع منع التكرار المتزامن وإعادة إرسال اللقطة المقبولة. يمكن إرسال نسخة جديدة عند تغير بيانات التقرير بعد معاينة جديدة.
- استجابة Graph `202 Accepted` تعني قبول الطلب، ولا تثبت وصوله للمستلمين. الانقطاع بعد بدء الإرسال ينتج حالة غير مؤكدة، وتُمنع إعادة المحاولة الآلية أو إرسال تقرير آخر للتاريخ نفسه حتى التحقق من العناصر المرسلة وتسوية الحالة إداريًا.
- سجل الاحتفاظ لا يحتوي رمز Outlook. توجد حماية مستقلة للخادم عبر `SANAM_MAIL_DISPATCH_SECRET`؛ يولّد ويضبط من جهة التشغيل، ولا يُطلب من الموظف أو مسؤول البريد إدخاله.
- الاختبارات تستخدم حسابات وطلبات وهمية فقط؛ لم يرسل التطوير رسائل إلى الفريق.

المراجع: [تدفق Authorization Code وPKCE](https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-auth-code-flow)، [Microsoft Graph sendMail](https://learn.microsoft.com/en-us/graph/api/user-sendmail?view=graph-rest-1.0).
